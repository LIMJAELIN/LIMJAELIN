# 임재린

Java와 Spring 기반으로 ERP 백엔드를 개발하고 있습니다. 인사·근태·급여 업무의 규칙을 기능으로 구현하고, 배치 처리와 외부 시스템 연동을 다룹니다.

## 기술

Java · Spring Boot · MyBatis · Oracle · PostgreSQL · REST API
